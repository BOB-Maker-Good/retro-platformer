# Retro Worlds

A from-scratch 2D 8-bit side-scrolling platformer using only vanilla JavaScript and HTML5 Canvas.

## Controls
- A/D or Left/Right: move
- Space/W/Up: jump
- Jump twice in the air for the double jump
- Hold jump for a higher jump

## Engine
- Fixed 120 Hz deterministic physics step
- Sub-pixel player position and velocity
- Custom AABB tile collision
- Horizontal acceleration/friction and air control
- Variable jump height + double jump
- Smooth camera tracking
- Data-driven/procedural world generation
- Coins, enemies, pits, flags and automatic world progression

Open `index.html` in a modern browser, or serve the repository with any static web server.
